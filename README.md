# Business Management System (BMS)

A full-stack Business Management System developed using Java, Spring Boot, React.js (Vite), and modern enterprise technologies. The application is designed to manage various business operations efficiently through secure REST APIs, role-based access control, and scalable backend architecture.

---

## 🚀 Features

### 🔐 Authentication & Authorization

* JWT-based Authentication
* Role-based Authorization
* Secure REST APIs using Spring Security
* Password encryption using BCryptPasswordEncoder

### 🏢 Business Management Features

* Employee Management
* Customer Management
* Product & Inventory Management
* Order & Billing Management
* Role & User Management
* Dashboard & Reporting

### 🌐 Frontend Features

* Responsive UI using React.js + Vite
* API integration with backend services
* Dynamic dashboard components
* Form validation and secure authentication flow

### ⚡ Performance & Optimization

* Optimized REST APIs
* Layered architecture implementation
* Efficient database operations
* Exception handling and validation

## ▶️ How to Run the Project

### Backend

1. Clone the repository
2. Configure database in `application.properties`
3. Run the Spring Boot application

```bash id="2x9u44"
mvn spring-boot:run
```

### Run Frontend

```bash id="7v6g31"
npm install
npm start
```
